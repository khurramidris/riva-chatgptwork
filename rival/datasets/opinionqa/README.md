# OpinionQA qualification subset

Source: SYN-DIGITS at commit `db891b6f821c914455b11763a96679864bf4fc48`.

- `questions.json` is the upstream `Qs_likert_scale_5_choices.json`: 489 five-choice Pew survey questions with human choice counts.
- `persona_answers.csv` contains released answers for 2,058 synthetic personas.

The files are incorporated for Rival's family-held-out population-distribution benchmark. See the repository-level `THIRD_PARTY_NOTICES.md` and `upstreams.lock.json` for attribution, permissions, and hashes.
